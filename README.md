## 🔍 Troubleshooting Common Issues

### Cannot Connect to sim-foundry

Make sure sim-foundry is running before you start your testing application. Also check that the IP address and port shown in Connection Settings match what you're using in your software.

### Simulation Seems Slow

Check your firewall settings if you're connecting from a different computer. If everything is on your local machine, close any programs that might be consuming significant processing power.

### Devices Not Responding

Click on each device in your simulation canvas to verify it's active. Look for the green "Running" indicator next to each device's name.
